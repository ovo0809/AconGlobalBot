# 邀请他人测试真实连续语音

真实分享使用本机原服务的 OpenAI 配置，不复制密钥，不启动第二个费用账本。公开入口与本机共用同一 Node 进程、SQLite 和费用保护：每案例 $8、组织每天 $40、每月 $160，已有待核对预留继续占用额度。

## 使用方式

确认本机生产 Demo 正在运行，配置为 OpenAI 文字与实时语音、Whisper 输入转写，然后执行：

```powershell
npm run share:live
npm run share:live -- --status
npm run share:live -- --stop
```

启动器只新增一个 Cloudflare 临时 HTTPS 隧道，指向同一服务的 `127.0.0.1:3003`。当前分享有效 24 小时；到期、手动停止或网络中断后不可继续。电脑、本机服务和共享启动器都需要保持运行。重启分享生成新链接、新账号，旧邀请失效。

成功后 `output/shared-live/真实语音测试邀请-顾问1.md` 和 `真实语音测试邀请-顾问2.md` 各含一位测试者的链接、账号、密码和步骤。分别交给测试者，不要两人共用账号；不要公开默认本机账号或 API 密钥。

测试者使用电脑 Chrome／Edge 打开 HTTPS 链接，登录后新建一位虚构客户，进入客户访谈、选择入口，点击一次“开始连续语音对话”并允许麦克风。随后持续说话，AI 自动回复并显示字幕。点击“结束对话”停止音频、返回顾问案例，由后台生成报告及 PDF；邮件继续只预览。

本次公网入口聚焦实时访谈；长会谈录音上传仍只在本机开放。原模拟分享命令 `share:demo` 独立保留。

## 隔离与费用

- 测试顾问属于原组织，但只能访问各自案例；本机已有顾问、Charles、管理员不能从公网入口登录，测试账号也不能从本机入口登录。
- Cookie 和语音令牌绑定本机／公网范围及本次分享编号。不同账号、旧邀请、本机和公网之间不能交换会话或语音令牌。
- 公网入口验证完整 HTTPS Origin／Host，并强制 Secure Cookie；不返回组织用量或费用记录，后台费用保护照常执行。
- 停止分享只关闭公开入口和它的语音连接，本机通话与费用记录不被清空。测试资料继续保留；测试者可按原回收站流程删除自己的案例。
- 数据库 schema 8 为原会话和语音令牌增加范围字段，旧记录默认属于本机。上线前备份，迁移后核对原业务与账本。
- 临时域名可能需要等待 DNS 生效；启动器先确认隧道连接注册，再检查公网接口。不能因得到链接就宣称真实语音通过。

真实 API、浏览器自动测试、实体麦克风、手机和 Charles 业务验收分别记录于 [验收账本](acceptance.md)，不能互相替代。
