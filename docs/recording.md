# 录音转写＋会后报告

本模式用于顾问与客户真人会谈，AI 在会后整理资料。原“开始客户访谈”仍提供 AI 主动提问和语音回复。

## 使用步骤

1. 在顾问的“客户”工作区建立新案例，点击“录音转写＋会后报告”或“会谈录音”。已有访谈或报告的客户请使用“新案例”。
2. 确认已获得参与者录音同意，允许浏览器访问麦克风，开始会谈。保持网页打开、电脑唤醒，避免锁屏、休眠或关闭浏览器。
3. 最多记录 120 分钟实际音频；暂停不计入时长。每分钟自动上传，暂停或结束时保存不足一分钟的尾段。断网时暂停并提示重试，服务器已保存的段可在刷新后恢复；未上传的音频可能丢失，会标记不完整。
4. 点击结束，停止麦克风并进入后台转写。转写进度保存，失败时保留已完成段，可明确重试剩余部分。
5. 核对原转写与音频，修正听错文字，将每段标为客户、顾问或待确认。只有客户片段用于事实提取；不能把顾问建议、假设或问题当成客户事实。
6. 确认客户原话后，后台分批提取并生成内部报告及 PDF。此时清除活动数据库中的暂存音频；转写原文、修订及时间来源继续保留。报告完成前或失败时不能标记生成成功。
7. 在“内部报告”查看、核对来源和 PDF；“通知预览”仍只预览，不会自动发送邮件。

## 配置与费用保护

```dotenv
# 模拟验收，不调用云端
RECORDING_PROVIDER=mock
RECORDING_TRANSCRIPTION_MODEL=whisper-1
```

真实模式显式设置 `RECORDING_PROVIDER=openai`，使用已安全配置的 OpenAI 密钥；提取与报告由独立 `LLM_PROVIDER` 配置控制。省略录音 Provider 时继承 LLM_PROVIDER，未配置两者则为 mock。模拟转写显示示范文字，不声称识别了实际录音。选择 OpenAI 但配置缺失或调用失败会明确报错，不能静默改用模拟结果。

录音期间不建立 Realtime 连接，也没有 AI 语音回复费用。每段转写、事实提取、报告都进入原案例／组织日／月账本，每案例 $2、每天 $5、每月 $20 不变。转写按可信 WAV 时长预留和估算；上游请求结果不明确时保留未决占用，刷新或重试不会清零。已有消费和未决记录会减少可用额度，120 分钟采集上限不保证剩余额度足够处理整场。

当前 whisper-1 的公开价为 $0.006／分钟，仅转写 60／90／120 分钟分别约 $0.36／$0.54／$0.72；事实提取和报告另计，账单以供应商为准。官方已宣布 whisper-1 将于 2027-02-26 停用，届时需迁移独立转写 Provider 并重新验收费率和结果格式。[官方转写文档](https://developers.openai.com/api/docs/guides/speech-to-text)

## 数据与验证边界

- 音频和未核对转写只对归属顾问开放，不对客户模式、其他顾问、Charles 或管理员开放；Charles 查看交接后的事实与报告。
- 录音暂存于本机应用数据库，不是浏览器无限缓存。确认后删除活动音频，案例彻底删除清除该案例的全部录音和转写；已下载内容与既有备份不随应用删除。
- Whisper 片段时间不是可靠的说话人标签。人工核对是必要步骤；选为客户发言也不等于客户事实已由顾问核实。
- 自动测试可证明分段、上传、费用、权限和报告流程；不能证明真实一小时麦克风稳定性、识别质量、噪声表现、锁屏行为或目标手机通过。最新证据见 [验收账本](acceptance.md)。
