# 邀请别人体验模拟 Demo

临时 HTTPS 地址运行在这台电脑上，使用独立合成数据库、两个分别拥有案例的顾问测试账号。文字访谈、转写与报告强制使用演示规则，真实 AI、连续语音和邮件投递未启用。

## 启动、查看与停止

前提：Node.js 24、已安装项目依赖，以及本机已有的 `cloudflared`。不需要 Cloudflare 账号或域名；安装位置不同可设置 `CLOUDFLARED_PATH`。

```powershell
npm run share:demo
npm run share:demo -- --status
npm run share:demo -- --stop
```

启动器在 Git 忽略的 `output/shared-demo/<时间>/` 创建源码副本、数据库和构建产物，监听 `127.0.0.1:3002`，通过 Quick Tunnel 对外提供 HTTPS。它不构建原 `.next`，不重启本机 3000 服务。启动时检查并预占端口；停止命令通知当前共享启动器，不按陈旧进程编号结束其他程序。

终端显示链接和测试账号文件位置。`output/shared-demo/current.json` 保存当前状态，不含密码；本次目录内的 `tester-credentials.json` 只含两个顾问账号。所有账号密码均独立随机生成，默认演示密码无效。共享入口不开放管理员及 Charles 登录。

启动成功后会更新 `output/shared-demo/测试邀请-顾问1.md` 和 `测试邀请-顾问2.md`，内含对应账号、链接和体验步骤。分别私下交给两位测试者；共用账号的人会看到相同案例。只使用虚构资料。关闭共享进程、电脑休眠或断网后链接不可用；重启产生新地址、账号及新合成数据库，旧测试数据留在原共享目录，不自动迁入或删除。

## 测试流程

1. 顾问登录，创建虚构客户及案例。
2. 进入客户模式、选择入口，用文字回答演示问题。
3. 结束返回顾问，查看内部报告和 PDF。
4. 查看完整邮件预览及提交复核；共享版不开放 Charles 登录，不据此验收实际复核。
5. 删除测试案例，在“已删除案例”还原或输入确认文字彻底删除。

录音模式的转写也是模拟结果，不能用它判断真实识别质量。共享版不启用真实连续语音。

## 数据和费用

源码副本采用明确的文件清单，不复制本机 `.env.local`、数据库、备份、日志和 Git 目录。子进程只继承必要系统变量，云端密钥为空。启动检查要求三个 Provider 都为 `mock`、邮件为 `dry_run`；配置不符则拒绝启动。

保留每案例 $8、每天 $40、每月 $160 的保护配置；模拟版不产生真实调用。本机原账本及待核对预留不变。**不能直接把共享副本切换成真实 API**：两个数据库账本独立，真实共享前必须另行解决组织总额度共用和访问控制。

## 公网链路检查

```powershell
node --import tsx scripts/check-shared-demo.ts
```

该检查通过当前公网地址，使用独立 Chromium 会话创建一份合成案例，验证登录、账号隔离、访谈、报告、PDF、回收站，再清除自己创建的案例。证据保存为本次目录的 `validation.json` 和截图，不打印密码。手机视口检查不等于实体手机或麦克风验收。

隧道依据：[Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。该服务用于临时测试，无可用性保证、不支持 SSE；本项目采用 HTTP 与 WebSocket。
