# 图片与视频资料库

Charles 使用本机复核账号登录 Demo 后，在左侧“设置”下面打开“资料库”。顾问须先把案例提交给 Charles 复核；Charles 只能为已分配给自己的案例上传和管理资料。上传资料保存在本机 SQLite，不会自动发布到公开 GitHub。顾问、管理员、客户模式和外部共享测试入口均不能列出资料、上传、查看原文件／版本、修改、批准、撤回或重试。

## 使用流程

1. 顾问先把目标案例提交 Charles 复核。Charles 登录后填写资料名称、来源说明，并从已分配案例中选择关联案例；处理调用计入该案例的现有额度。没有可选案例时，须先由顾问完成提交。
2. 选择图片或视频，确认有权使用并同意按已配置服务处理，点击“上传并自动提取”。OpenAI 模式将图片／关键画面和音轨提交至云端；模拟模式只生成明确标注的占位结果。
3. 页面显示等待处理、正在提取、待复核或失败。可查看原文件、AI 原始提取、各分段结果、覆盖范围和处理记录。
4. 对照原资料修改“人工复核稿”，特别核对金额、币种、日期、适用地区、条件、例外和免责声明；不清楚的内容保留待核对。
5. 勾选“已核对原资料及提取范围”后批准。默认仅关联案例可参考。只有资料确实不含客户个人信息时，才另行勾选“这是通用参考资料，不含客户个人信息，可供公司内所有顾问的案例参考”；批准快照随后采用组织范围，同一组织内除公共测试账号外的案例可由 AI 检索。其他顾问仍不能打开资料库、原文件或历史版本，Charles 也不会因此获得其他未分配案例的业务访问权。
6. 修改并保存已批准正文会取消当前参考资格，须重新批准。也可直接撤回参考资格；以后新检索不再使用，但已经建立的语音连接上下文和历史报告快照仍保留，需重建语音连接才采用新资料。

资料通过资料库复核只表示 Charles 允许系统在批准范围内参考，不代表外部政策、统计、产品条款或法律结论已经独立验证，也不能把资料内容当作客户事实。既有 GitHub `knowledge/` 参考路径保留；此复核门禁针对 Demo 上传资料。

## 处理范围

- 图片：PNG／JPEG／静态 WebP，原文件最多 8 MB、4000 万像素；浏览器缩放到最长边 2048 后提交视觉识别。小字缩放后可能难以识别，应拆成清晰局部图。
- 视频：小文件保留原有浏览器路径（最多 32 MB、10 分钟）。Windows 本机新增 MP4／MOV／M4V 最多 2 GB／2 小时的自动处理路径（WebM 仍限小文件路径），按 8 MB 分块上传，再由内置 MediaTranscoder 转码成最多三分钟、每段不超过 32 MB 的 MP4；浏览器逐段沿用现有抽帧与音轨提取。视频须有可解码音轨，系统不支持的编码明确报错，不伪造识别成功。
- 视频画面定时抽样并包含片尾，最多 20 帧，缩放到最长边 1280；达到 20 帧时由片尾替换最后一个定时样本。不是逐帧识别，短暂出现的字幕／图表可能遗漏。
- 声音转换成单声道 16 kHz WAV，新上传资料的首轮音轨按最多 15 秒分段交给 Whisper；10 分钟最多 40 个音轨段，服务端保留最多 41 个的兼容校验边界。历史 30 秒分段依然可读取和复核，不自动重写。音轨与视频时长差异最多 0.25 秒，尾部不足补静音、超出裁去，差异记入覆盖范围；更大差异拒绝处理。
- 从第二个音轨段起，只把相邻前段末尾最多 220 UTF-8 bytes 的转写文字作为 Whisper `prompt`，用于延续语境；该提示不能成为当前音轨的文字或来源。严格会谈录音转写不发送该资料上下文。该用法参考 [OpenAI 文件转写说明](https://developers.openai.com/api/docs/guides/speech-to-text)。
- Whisper 的句级时间若越界、重叠或缺少元数据，资料提取保留完整转写，并只定位到该段原音轨，在正文与处理记录提示核对；整段回退不充当精确句级覆盖。原始转写可能存在重复、错字或漏字，须播放视频复核后再批准。
- 新上传视频首轮转写后自动检查：连续至少 5 秒没有对应转写、且其中至少 1 秒存在明显音频信号时，标出疑似缺口时间范围；句级时间越界／重叠或缺少元数据的粗时间段也进入有限补转写候选。该启发式不能区分语音与音乐，也不能发现所有漏字。
- 每份已准备资料的所有音轨段共用最多 4 次、每次不超过 12 秒的补转写；仍不能证明覆盖时，所有疑区共用最多 6 张补画面。不是每个 15 秒段各自 4 次；候选过多时，尽量在开头、中间和末尾疑区间分配有限次数，不保证补完所有疑区。补转写和补画面分开保存，画面不是语音原文。大视频准备分段不会绕过每案例 $8／每天 $40／每月 $160 总上限。
- 自动补帧目前使用 Windows 本机解码；每批最多两个本机进程，单进程超时 60 秒，结束后清理临时媒体。标准化后的时长偏差超过 1 秒会拒绝处理，字幕来源采用“约时间点”。编码不支持时仍保存已完成的转写并提示；当前本机 VP8/Opus WebM 不支持后台补帧，不影响已完成的浏览器首轮抽样。
- 这项有限补提取是用户已授权的例外：每次仍走原费用预留、结算、预算拒绝和未知费用保护。它不同于过去禁止的“对未知收费／普通失败自动付费重试”：预算拒绝、未知费用、上游失败、已经 `started` 后中断或无法证明覆盖时不再自动重放，也不以猜测补写内容。处理记录会显示尝试、停止原因和仍需注意的时间范围。
- 自动补提取不等于资料完整或可供 AI 参考。存在疑似缺口时资料仍显示 `attention`；无论是否补到内容，均须 Charles 最终复核并明确批准后才可被 AI 使用。仅新上传资料进入此流程，旧资料保持原文、版本和批准状态，不自动重跑。
- 本次对某份旧视频的人工修正、字幕核对及处理记录，与未来新上传视频的系统自动检查是两条独立证据；不得用人工修正证明自动识别准确率。
- 顶层转写正文与逐句分段不一致时，只有顶层正文明确包含分段并延续了尾文才可回退到整段来源；冲突或分段反而更多时拒绝处理，不静默舍弃。会谈录音的严格路径仍拒绝此类不一致。
- 已准备资料单次请求总量最多 64 MB，单人最多 60 份资料，本机已提交原件与处理分段合计最多 2 GB。大视频准备临时区另行限额和过期清理；分段分别计入资料数量。单份复核文字最多 64 KB；当前不支持无限长视频／批量 100 GB 导入。
- 提取依赖已有 OpenAI 文字模型和 Whisper 配置。未完成真实 API 识别质量验收时，配置可用和模拟通过不代表真实提取已验收。

## 权限、费用与恢复

新接口 `/api/materials` 在读取前验证本机复核身份、来源案例当前分配、组织范围、来源和 CSRF；原文件不在公共静态目录。服务端拒绝顾问、管理员、客户、外部共享账号以及未获分配来源案例，不能依赖隐藏按钮实现权限。默认案例范围，通用资料必须单独明确确认并把批准快照记为 `organization`；只有同一组织内、非公共测试账号的案例可检索该快照。组织级检索只影响 AI 参考，不开放资料库管理、原件查看或额外案例业务访问。关联案例软删除后停止检索，彻底删除案例会一并删除关联上传、分段和版本，既有备份不随按钮清除。

既有由顾问上传的资料不会迁移、删除或改写原上传者、处理事件和不可变批准快照。案例提交给 Charles 后，当前复核者可继续管理；取消或改变分配后，原复核者立即失去管理权限。历史 `library` 范围仍保持原顾问边界，不会静默扩大；只有 Charles 对获分配来源案例重新勾选公司通用选项并批准，才生成新的 `organization` 快照。即使资料可供全公司案例的 AI 检索，管理权仍只跟随来源案例的当前复核分配。

图像识别复用现有 `extraction` 费用保护，声音复用 `transcription`；每次调用前原子预留、收到用量后结算，继续受每案例 $8／每日 $40／每月 $160 限制。前台不展示费用。额度不足时任务失败并保留已完成结果。未知用量仍保留待核对预留，不因重试或删除重置组织额度。

处理任务持久化，服务重启后中断任务标记失败，不自动重放可能已收费的请求。人工重试最多三次，只处理未完成分段；已完成分段不重复提交。上传使用请求编号去重。模拟生成的资料即使获准，也只用于模拟流程；切换真实服务后不会混入真实参考。

上传资料不进入共用的 GitHub 缓存。文字回复每轮、语音每次建立连接、报告每版从数据库读取当前可用版本，和现有 GitHub 片段一起排序，仍最多四段、约 6 KB。后台保存文件编号、内容版本、行号、摘录；内部报告和 PDF 保留来源，聊天框不显示资料卡。私有原文和历史版本只允许当前获分配的复核账号查看，顾问报告仅保留可核对摘录而不能打开私有原件。

## 大视频准备与恢复

大视频准备使用独立 `/api/material-imports`，沿用本机复核身份、CSRF、组织和已分配案例授权；临时目录不在公共静态目录。SQLite 只保存准备任务与分块哈希，媒体临时存到数据库旁的私有目录。分块重试须与已保存内容一致；每个准备段与原文件 SHA-256、转码时间轴的近似区间绑定（与原片可能有不超过 1 秒的编码偏差），提交资料时再次核对分段文件哈希。成功或取消后清理临时大文件，已提交片段、来源和处理记录保留；过期临时任务会清理，不能把准备区当长期存储。原视频由用户自行保留，数据库备份不包含准备中的临时文件。

会话刷新后可继续尚未完成的准备任务；源文件未传完时需重新选择同一文件。服务重启中断的转码标失败，需明确重试；已提交材料不会重复生成。每份片段仍须单独复核，不自动批量批准，也不扩大参考范围。案例彻底删除包含关联准备记录与临时文件；正在上传／转码的任务需先结束或取消。

## 验证边界

自动测试使用隔离数据库、合成媒体和假上游。真实 OpenAI 图片识别／视频声音转写、真实长视频内容准确率与目标手机操作需分别实际测试后记录，不能用自动测试代替。

视觉请求格式参考 [OpenAI Images and Vision](https://developers.openai.com/api/docs/guides/images-vision?api-mode=responses)，使用 Responses `input_image`；音轨沿用当前 `whisper-1` 分段转写实现。不依赖 Ollama，也未引入新的媒体转换服务或软件包。
