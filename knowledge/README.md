# Aeconn 投喂资料目录

这里用于存放供 Aeconn 后续整理、检索和接入 AI 的参考资料。

> 当前 GitHub 仓库是公开仓库，上传的文件和提交历史对外可见。请只上传有权公开分享的资料或合成示例。客户身份信息、真实录音、保单、财务资料、内部机密、API 密钥等不要上传；仅删除文件也不会清除 Git 历史。

## 如何上传

1. 打开本目录，点击 **Add file → Upload files**。
2. 拖入可公开的资料，填写资料来源和用途，再提交。
3. 可以按主题自行建立子文件夹，例如产品说明、访谈示例、业务规则。

可存放 Markdown、TXT、PDF、Word、表格等资料；这些格式在这里仅作为文件保存，并不代表系统已支持自动解析。

建议文件名：`YYYY-MM-DD_主题_v1.pdf`。资料应尽量注明：
- 来源、作者或机构，以及公开链接（如有）。
- 发布或更新日期、版本、适用地区和有效期。
- 使用授权、是否为合成示例。
- 复核状态：待复核／已由 Charles 复核；仅在实际完成复核后标记通过。

复杂资料可附同名说明文件，例如 `产品说明.source.md`，记录以上信息。

## 如何用于 AI

上传到本目录**不会自动接入当前 Demo，也不会触发付费 API 调用**。后续需要单独实现资料解析、检索、来源引用和业务规则审核。

资料中的内容应作为待核对的参考，不能直接当作客户事实或已批准的业务规则。示范规则保持 `demo_unapproved`，经 Charles 确认后再按批准范围使用；未知或冲突内容保留为待确认，不得补造。
