# 给 Charles 的资料投喂入门

更新日期：2026-10-31。先记住：**上传 → 自动提取 → 核对 → 批准 → AI 按需参考**。上传成功不等于已允许 AI 使用，更不等于内容完全正确。

## 现在能读什么

| 文件 | 当前可用方式 |
| --- | --- |
| 海报、截图、图文图片 | Demo「资料库」上传 PNG、JPEG、静态 WebP，单张不超过 8 MB；小字请拆成清晰局部图 |
| 有声音的视频 | 本机 Windows Demo 支持 MP4／MOV／M4V 单个最多 2 GB、2 小时，自动上传、压缩并分段；WebM 保留 32 MB／10 分钟的小文件路径 |
| Markdown、TXT、CSV | 现有公开 GitHub knowledge 文本路径；只放有权公开的参考资料 |
| PDF、Word | 当前上传入口不直接支持；先转清晰图片或文本 |

视频会转写声音，并约每 30 秒抽取一张画面。短暂出现的字幕／表格可能漏掉，必须对照原片。已实测约 79 秒视频的真实视觉／Whisper 提取及修订批准；这不证明所有格式、长视频或保险内容都准确。

## 按按钮操作

下面的步骤适用于**运行 Demo 的电脑上，以 Charles 复核账号登录**。顾问账号不会显示资料库，也不能直接调用资料接口。

1. 先请顾问在案例的内部报告页面点击「提交 Charles 复核」。没有完成交接的案例不会出现在 Charles 的资料库选择项中。
2. 打开 Demo，以 `charles@aeconn.example` 登录复核工作区，点击左侧「设置」下面的 **资料库**。
3. 填写「资料名称」和「来源说明」。例如名称“长期护理基础介绍”，来源填写机构、日期和适用地区；选择一个已分配案例。
4. 选择图片或视频，勾选有权处理和理解提取范围，点击 **上传并自动提取**。要真正识别，页面应显示真实 OpenAI 提取；“模拟提取”只产生占位内容。
5. 等状态变成 **待复核**，点开该资料。对照原图或播放视频，检查「AI 原始提取」，在「人工复核稿」修正错字、重复、遗漏，重点核对数字、币种、条件、例外和适用地区。看不清或无法证实的内容写明待确认，不要猜。
6. 填写复核备注，勾选 **已核对原资料及提取范围**，点击 **复核通过并允许 AI 参考**。如想先保存但暂不启用，只点「保存复核稿」。
7. 确认出现“资料已复核，之后可供 AI 参考”，并检查「参考范围」。展开 **查看处理记录**，可看到画面／音轨分段、处理及批准事件。

默认只供关联案例参考。只有资料确实通用且不含客户个人信息时，才额外勾选「这是通用参考资料，不含客户个人信息，可供公司内所有顾问的案例参考」。批准后，同一组织内除公共测试账号外的案例可由 AI 检索这份资料；这不代表顾问能看到资料库或原件，也不代表 Charles 能打开未分配案例。历史 `library` 资料不会自动变成公司通用，必须先把来源案例交接给 Charles，再由 Charles 重新勾选并批准。

批准后，在对应案例发起与资料内容相关的问题。文字每轮会重新检索；已进行中的语音应暂停后重新连接。内部报告／PDF保留来源，聊天框按当前设计不展示来源卡片。AI只选相关片段，不保证每次回答都引用这份资料。修改后保存会撤回参考资格，须再次批准。

## 大视频也直接选文件

不用先把视频发给 Codex。填写名称、来源和关联案例后，直接选择原视频并开始上传。超过原有 32 MB 或 10 分钟限制时，Windows 本机自动处理会分块上传、压缩、切成最多三分钟的片段，再逐段提交提取。请保持 Demo 页面打开；本机准备不调用 AI，后面的视觉识别和语音转写才使用现有云端服务。

页面会显示上传、准备和分段提交进度。中断后可从任务继续；若文件尚未传完，按提示重新选择同一原视频，系统会核对已收到的分块。取消会停止后续处理并清理临时文件，已经提交提取的资料仍留在处理列表，供核对。

长视频会在资料列表中形成“第 1/N 段”等条目，按段检查并批准。覆盖范围保留原文件名、文件校验值和转码时间轴的近似区间（与原片可能有不超过 1 秒的编码偏差）。自动压缩不能代替人工核对；小字、短暂画面和转写仍可能遗漏。达到费用上限时不会自动提高额度，已完成结果保留，按错误提示处理后再重试。

上限 2 GB／2 小时是应用允许的边界，不代表本机已完成两小时或 2 GB 全量压力测试；实际测试结果以验收账本为准。非 Windows 服务端仍可使用原有小视频路径（32 MB／10 分钟），系统不支持的编码会明确报错。

## Charles 怎样使用

Charles 现在可用本机复核账号按上述步骤上传和批准资料；顾问只能提交案例，不能操作资料库。`127.0.0.1` 仍只能在运行 Demo 的当前电脑访问，外部共享访谈链接也没有开放资料库。若需要 Charles 在自己的电脑独立上传，仍须另做受保护的远程 HTTPS 资料入口；不要把当前共享访谈链接当作资料上传地址。

费用保护仍为每案例 $8、组织 UTC 每天 $40、每月 $160。真实提取会使用 API 额度；失败时查看原因再重试。私有原文件、提取稿和处理记录保留本机，不自动上传 GitHub。

详细限制见[资料库说明](materials.md)，实际测试边界见[验收账本](acceptance.md)。
