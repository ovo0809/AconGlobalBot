## 状态怎么读

- 待提取／处理中：尚未产生完整文字，不能当作已读取。
- 已提取、待核对：已有草稿，但还没有完整对照原资料。
- AI 对照核对完成：只表示核对了转录与原资料的一致性，不代表人工批准或业务准确性。
- 检索通过：用 Demo 实际检索代码得到该文件的固定版本、行号和摘录；不等于真实模型已准确使用。
- 部分完成／失败：详细记录必须列出缺失页面、时段或原因。
- 业务复核：仅由 Charles 或获授权业务人员实际确认后更新；没有复核人和证据不能标为通过。

正文放在 `knowledge/提取文本/`；每份详细记录命名为 `资料名.source.md`。现有读取器会排除所有 `README.md` 和 `*.source.*` 文件，因此这个列表与操作记录不会混入业务检索。链接是供人查看，不会让 Demo 自动抓取外部页面。

图文记录注明原图版本、文件校验值与版面区域；视频记录还需注明总时长、已处理时间段、讲话转写与画面识别各自的覆盖情况。当前没有处理任何视频。
