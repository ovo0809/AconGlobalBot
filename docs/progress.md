# Demo 当前进度

更新日期：2026-10-31（America/Los_Angeles）。本页便于查看当前实现；详细证据以[工程验证](verification.md)和[验收账本](acceptance.md)为准。

| 功能 | 当前状态 | 仍需实际验证 |
| --- | --- | --- |
| AI 客户访谈 | 保留文字及连续语音；围绕客户目标精简提问，复用已有回答并补问关键缺口 | 新策略的真人自然度、完整性及目标手机 |
| 真人长会谈 | 独立录音转写模式，分段保存、说话人核对、事实与会后报告 | 实体麦克风连续 60–120 分钟 |
| 私有资料库 | 图片／短视频上传、自动提取、编辑复核、批准／撤回、处理记录；默认只供关联案例参考 | 更多格式、长视频及内容准确率 |
| 短视频示例 | 已完成约 79 秒视频的真实视觉／Whisper 提取、字幕画面核对、修订批准及带来源检索 | 不等于逐字听审或 Charles 业务确认 |
| 公开 knowledge | 保留长期护理海报、提取文本及资料处理列表；与私有资料分开管理 | 外部统计、政策和具体产品内容仍需业务核验 |
| 报告与 PDF | 基于保存的客户事实，资料来源另存版本／行号／摘录；邮件保持完整预览 | Charles 内容验收；不自动实际发送 |
| 界面与案例 | 居中访谈窗口、资料库滚动条、客户／复核列表、回收站还原及彻底删除 | 浏览器视口测试不等于实体手机测试 |
| 费用与共享 | 用量结算／待核对处理，模拟及真实语音共享入口，访问范围隔离 | 应用账本不等于供应商最终账单 |

费用保护保持 **每案例 $8、组织 UTC 每天 $40、每月 $160**。本次同步不新增付费 API 调用，不修改已有费用账本或本机密钥配置。

以后上传图片／视频请使用顾问工作区的 **资料库**：上传并提取 → 对照原件修订 → 复核通过后允许 AI 参考。图片上限 8 MB；视频上限 32 MB、10 分钟，画面每约 30 秒抽样一次。更大素材目前需先压缩或分段，尚无超大文件自动切分／断点上传。[完整操作说明](materials.md)

GitHub 仅同步代码、合成测试资料、公开 knowledge 和进度文档。用户上传的原视频、私有提取／复核稿、数据库、密钥及本机证据不进入仓库。仓库示例配置默认 mock，不依赖 Ollama。
