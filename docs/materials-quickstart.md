# 给 Charles 的资料投喂入门

更新日期：2026-10-31。先记住：**上传 → 自动提取 → 核对 → 批准 → AI 按需参考**。上传成功不等于已允许 AI 使用，更不等于内容完全正确。

## 现在能读什么

| 文件 | 当前可用方式 |
| --- | --- |
| 海报、截图、图文图片 | Demo「资料库」上传 PNG、JPEG、静态 WebP，单张不超过 8 MB；小字请拆成清晰局部图 |
| 有声音的短视频 | 上传浏览器可解码的 MP4／WebM，单个不超过 32 MB、10 分钟；MOV 取决于编码 |
| Markdown、TXT、CSV | 现有公开 GitHub knowledge 文本路径；只放有权公开的参考资料 |
| PDF、Word、超大视频 | 当前上传入口不直接支持；PDF／Word 先转清晰图片或文本，大视频先分段／压缩 |

视频会转写声音，并约每 30 秒抽取一张画面。短暂出现的字幕／表格可能漏掉，必须对照原片。已实测约 79 秒视频的真实视觉／Whisper 提取及修订批准；这不证明所有格式、长视频或保险内容都准确。

## 按按钮操作

下面的步骤适用于**运行 Demo 的电脑上，以本机顾问账号登录**。

1. 打开 Demo，登录顾问工作区，点击左侧「设置」下面的 **资料库**。
2. 填写「资料名称」和「来源说明」。例如名称“长期护理基础介绍”，来源填写机构、日期和适用地区。选择关联案例；没有案例时先建立一个专用的合成资料整理案例。
3. 选择图片或视频，勾选有权处理和理解提取范围，点击 **上传并自动提取**。要真正识别，页面应显示真实 OpenAI 提取；“模拟提取”只产生占位内容。
4. 等状态变成 **待复核**，点开该资料。对照原图或播放视频，检查「AI 原始提取」，在「人工复核稿」修正错字、重复、遗漏，重点核对数字、币种、条件、例外和适用地区。看不清或无法证实的内容写明待确认，不要猜。
5. 填写复核备注，勾选 **已核对原资料及提取范围**，点击 **复核通过并允许 AI 参考**。如想先保存但暂不启用，只点「保存复核稿」。
6. 确认出现“资料已复核，之后可供 AI 参考”，并检查「参考范围」。展开 **查看处理记录**，可看到画面／音轨分段、处理及批准事件。

默认只供关联案例参考。只有资料确实通用且不含客户个人信息时，才额外勾选「这是通用参考资料，不含客户个人信息，可用于我名下其他案例」。**这里的“我名下”只指上传顾问账号，不会自动开放给公司所有顾问。**

批准后，在对应案例发起与资料内容相关的问题。文字每轮会重新检索；已进行中的语音应暂停后重新连接。内部报告／PDF保留来源，聊天框按当前设计不展示来源卡片。AI只选相关片段，不保证每次回答都引用这份资料。修改后保存会撤回参考资格，须再次批准。

## Charles 怎样使用

**Charles 现有复核账号暂不能上传，外部共享测试链接也未开放资料库。** `127.0.0.1` 只能访问当前电脑，发给远程的 Charles 不能打开你的 Demo。

- 现在最快的办法：Charles 把资料交给本机顾问，由顾问按上述步骤上传，结合 Charles 的核对意见修订，再明确批准。
- Charles 在这台电脑亲自操作时，需要使用具有资料管理权限的顾问账号；现有 Charles 复核角色不具备该权限。
- 若需要他在自己的电脑独立上传，还需另做专用账号、远程 HTTPS 资料入口和跨顾问资料发布范围。这些能力尚未完成，不要把当前共享访谈链接当成资料上传入口。

费用保护仍为每案例 $8、组织 UTC 每天 $40、每月 $160。真实提取会使用 API 额度；失败时查看原因再重试。私有原文件、提取稿和处理记录保留本机，不自动上传 GitHub。
