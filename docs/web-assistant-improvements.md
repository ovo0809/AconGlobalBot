# 参考网页助手的最小访谈改进

日期：2026-11-06。基线：`64a725ec7f13120c0e70b54428dfe02d67a29466`；原开发生成的 `next-env.d.ts` 变化保留。

## 有证据的启发

- [McDonald’s 英国招聘流程](https://www.mcdonalds.com/gb/en-gb/help/faq/can-you-provide-information-on-the-recruitment-process.html)将采集、筛选、评估和真人面试分步展示；这是英国页面的说明，不推断美国每个门店的相同配置或量化效果。
- 本轮还经 Browser 从美国官方 Careers 进入 [McHire](https://jobs.mchire.com/)并展开 Olivia：开场先说明助手任务、会话资料处理和回答可能出错；未回复、未投递申请，不能据此认定测试过回答质量或预约能力。
- [California DMV 联系入口](https://www.dmv.ca.gov/portal/contacting-dmv/)与[在线服务](https://www.dmv.ca.gov/portal/dmv-online/)区分信息问答、办理路径与人工帮助。浏览器实看官方主页 Ask DMV 的隐私提示；未进入实际会话，不声称测过机器人问答、记忆或人工服务。
- 可借鉴的是清楚的下一步、解释采集目的和不惩罚的人工出口。Aeconn 已有四主题、答案复用、未知／拒答、冲突澄清和有界收尾，不将这些重复包装为新增功能。

## 当前代码证据与改动范围

`lib/interview.ts` 的本地控制只识别少数停止、致谢和进度表达；`lib/service.ts:respondToText()` 在模型调用后才执行 mock 控制分支。纯“为什么问这个”“我想找顾问”尚未作为独立帮助意图处理；非金额 mock 解析会将普通文本作为候选事实，因而需要在进入解析前处理这些精确控制消息。

最小范围：

1. 在既有访谈模块中增加／复用共享的精确独立控制入口，保留旧导出兼容。解释本次问题目的，或指向现有结束与交还按钮；控制回复不提出新问题、不生成事实、不自动结束音频、不承诺回拨或邮件。
2. 在当前会话／epoch 校验后处理本地控制，再决定是否加载知识和请求模型。普通事实回答仍走原模型／mock 来源校验和费用保护；云端失败不静默降级。
3. 给共享语音提示补充对应交互规则；真实语音仍由原语音模型执行，不把提示词或假上游测试当作真实行为验收。
4. 客户欢迎区／说明区加入轻量的三步旅程与可用表达，不加入固定时长、进度百分比、内部事实画像或资料引用。

## 修改前锁定的回归与验收标准

- 当前 session 的独立“为什么问这个／为什么要问收入”只解释当前问题或给保守的通用说明，不增加问句，不创建、覆盖或确认任何事实。
- “我想找顾问／转人工”提示点击现有“结束对话”并交还设备；不替用户触发结束／报告／发送。
- 历史 session、非最终字幕、助手文字和越界消息不能触发当前帮助；含实际财务答案的混合表达不得被本地帮助匹配吞掉。
- 配置云端时，纯本地控制不触发 provider、知识请求或费用预留；原客户消息和控制回复仍依照原去重与 epoch 规则保存。
- 既有停止、致谢、进度、正常回答、未知、拒答、冲突及失败重试回归保持。四保险主题、来源事实、审批、收件人、邮件 dry-run、单 InterviewAgent 和 $8／$40／$160 不变。
- UI 只展示受限客户可见说明；390px 与桌面无溢出，原输入、语音、暂停、结束和交还流程可操作。

先增加能复现缺口的测试并记录失败，再修改对应模块；完成后运行相关单测及服务回归，再按影响范围检查 typecheck、lint、全量单测、隔离构建及浏览器流程。真实 API、实体麦克风、手机和 Charles 业务效果本轮不测试；结果据实写入工程／验收记录。

## 保持的边界

不新增公开客服层、报价、理赔、申请状态、CRM 集成、电话回拨、交易、数据库 schema、外部服务或新依赖。DMV 公共助手的“不输入个人资料”不等于 Aeconn 已认证保险访谈完全不采集资料；沿用现有明确建档与受限访谈规则，不能作出新的隐私承诺。
